# DK-1043 · Device check: tool output shows in the Files apps under Dokulo (DK-0006)

Added by agent-2, 2026-10-07 22:35.

DK-0006 (FileStore + fileStoreProvider) is unit-tested with temp dirs; its first acceptance criterion needs a device. Android (emulator-5562 under team.py device, API 34 and, if available, API 28): save a file through FileStore.save (any tool, or a debug button) and check it appears in the Files app under Documents/Dokulo; delete it in the Files app, pull to refresh in Dokulo, check the index drops it. On API 28 the WRITE_EXTERNAL_STORAGE runtime permission must be granted first (the permissions flow asks for it). iOS simulator: the file appears in Files under On My iPhone > Dokulo (UIFileSharingEnabled, LSSupportsOpeningDocumentsInPlace). Record results here; file a bug with team.py add for any failure.
