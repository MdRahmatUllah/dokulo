# DK-1055 · pdf_structure: a larger or bolder top-band line is a heading, not a running header (DK-0401 finding)

Added by agent-1, 2026-10-07 23:39.

dropRunningLines normalises digits, so 'Kapitel 1 · Abschnitt 1', 'Kapitel 1 · Abschnitt 2'… in the top 12 % band count as one repeated header and are dropped (test/fixtures/long-300-pages.pdf: no chapter heading survives). A line larger than the body size or bold must not count as running. Acceptance: long-300-pages.pdf pages 1–2 each give a heading block; the existing running-header tests still pass. docs/evaluations/pp-doclayout.md.
