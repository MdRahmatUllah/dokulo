# DK-1041 · Device check: deep links cold-start every route (DK-0004)

Added by agent-2, 2026-10-07 22:11.

DK-0004's routes are covered by widget tests that cold-start the router at every route. The device half of its acceptance criterion needs Dokulo's emulator. Steps: hold emulator-5562 (team.py device), install a debug build of app_pdf, force-stop it, then for each route in docs/Developer guide.md section 3 run: adb -s emulator-5562 shell am start -a android.intent.action.VIEW -d "dokulo://open/<route>" (e.g. dokulo://open/tool/compress, dokulo://open/viewer/f42?mode=edit). Expected: the app opens straight to that screen (the placeholder shows its screen ID), with the tab bar only on tab routes, and back from a full-screen route lands on a tab. On iOS, the same with xcrun simctl openurl booted "dokulo://open/<route>". Record the results here; file a bug with team.py add for any route that fails.
