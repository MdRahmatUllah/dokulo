# DK-1081 · Image to PDF: HEIC input, decoded by the platform (DK-0432 follow-up)

Added by agent-0, 2026-10-10 04:06.

DK-0432's engine runs on a pure-Dart worker: the image package and OpenCV can't read HEIC, so a HEIC fails as damaged there. Spec (DK-0432): HEIC native on iOS / Android 9+. Do: in app_pdf, before the job starts, convert each HEIC/HEIF the user picked to a JPEG in the job's input temp folder with the platform decoder (a permissive plugin, e.g. flutter_image_compress, under the pubspec lock; or a small method channel: UIImage / ImageDecoder on Android 9+), keeping EXIF orientation; below Android 9 show the catalogue's unsupported-file banner. Acceptance: a HEIC photo from an iPhone becomes a page, turned right; widget test for the conversion step; licence register updated.
