# DK-1080 · X2 failure: Skip this page and Send report by email

Added by agent-0, 2026-10-10 01:23.

From the tool-shell-failure visual QA (DK-0847): the X2 failure state of an unexpected error offers three actions in the frame (Try again primary · Skip this page secondary · Send report by email tertiary); T2 shows Try again only. (1) Send report by email: open crash_log.dart's reportEmail(code, device, entries) in the user's mail app (needs url_launcher in the licence register, under the pubspec lock); (2) Skip this page: only where the tool's job can continue past a page (a ToolDefinition/ToolJob flag), else hidden. DkProgressError takes more than one action (secondary, tertiary). Acceptance: the failure frame's three buttons for a job that supports skipping; Send report opens a draft email with the code.
