# DK-1142 · M3 Scanning pages vs frames: inset card, filter picker thumbnails and check, file name token chips and preview card; licence header as a caption

Added by agent-3, 2026-10-16 07:46.

Found in visual QA DK-0940, DK-0947, DK-0949, DK-0950 (22-me-settings/me-scanning, me-licence, me-filename, me-filter; goldens scanning_settings_*, scanning_filter_*, scanning_filename_*, licence_* in test/screens/; docs/qa/me.md).

1. me-scanning: the seven rows sit in a full-width group; the frame (like Language, Appearance, Licences) puts them in an inset card (16 margin, radius, outline).
2. me-filter (Default filter): the app lists five radio rows (radio left). The frame: an inset card of rows, each with the filter's page thumbnail on the left, name and description, and a check on the right of the chosen one; the caption under the card matches.
3. me-filename (File name): the field shows the raw pattern 'Scan {date} {time}' with a clear button; the frame shows the tokens as chips inside the field ('Scan [date] [time]', §23 'editor with token chips'). Insert chips: the frame's are neutral (outline, text colour); the app's are primary. The preview: the frame puts 'Preview' (caption) and the name in a card; the app has a heading and the name as plain text.
4. me-licence: the header 'Material Symbols · Apache-2.0' is a title; the frame's is a small grey caption over the monospace text.

Acceptance: each golden matches its frame in light, dark and German.
