# DK-1089 · V1 night mode rendering (canvas and pages), without the chrome

Added by agent-0, 2026-10-10 07:52.

The chrome-independent part of DK-0304: DkPdfCanvas.night inverts the pages (dark, light text, hue kept) on color.nightCanvas #0B0D10 (UI spec §17.1); V1 reads it from prefs (viewer.night). The switch is in the overflow menu (DK-0295, after DK-0294). Images are inverted too (one filter); un-inverted images need per-object rendering. Acceptance: viewer test with night on; token in both themes.
