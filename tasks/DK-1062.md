# DK-1062 · pdf_structure: ID numbers don't make an address block a totals table (DK-1056 follow-up)

Added by agent-2, 2026-10-08 00:14.

agent-1's review of #981: PdfStructure._isTable treats a last column that is mostly digits as totals, so an address block whose right column has two ID lines (Steuer-ID 86 095 742 719, IBAN DE00 …) could still come out as a table. Fix: count only amount-like cells as numeric (a currency sign or %, or a decimal number with at most 2 decimals), not long digit groups. Test: a synthetic two-column block with a Steuer-ID and an IBAN on the right stays paragraphs; the invoice totals stay a table.
