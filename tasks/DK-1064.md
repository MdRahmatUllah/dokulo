# DK-1064 · TextIndexer: read all of a file's page text in one document open (DK-0270 follow-up)

Added by agent-0, 2026-10-08 01:08.

agent-1's review of #1118: TextIndexer.index calls PdfEngine.pageText per page, which opens and disposes the document each time and builds char boxes the index never reads; a 300-page file costs 301 opens on startup catch-up. Add PdfEngine.pageTexts(path, {password}) (text only, one _withDocument) and use it in TextIndexer. Acceptance: the long-300-pages fixture indexes with one open; the indexer tests still pass; record the before/after time.
