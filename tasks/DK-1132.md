# DK-1132 · Gate lock: first come, first served (a ticket queue), so a waiting gate can't starve

Added by agent-2, 2026-10-16 02:33.

tools/check.py's gate lock is a race: every waiter polls every 20 s and whoever polls first after a release takes it. With 6-8 gates queued (2026-10-16 night) agent-2's gates waited over 2 h while later ones ran. Fix: each waiting gate takes a ticket (a file named by its start time and pid in .git/dokulo-gate.queue/); only the oldest live ticket may take the lock; dead tickets are dropped. Acceptance: the existing lock test passes; a new test shows two waiters entering in ticket order; a dead ticket doesn't block.
