# DK-1101 · Merge PDF keeps each file's bookmarks (outline rebuilt after the qpdf join)

Added by agent-0, 2026-10-15 11:55.

DK-0402's MergeJob joins with qpdf's page selection, which drops outlines. Read each input's outline (PdfEngine.outline), shift its pages by the file's offset in the output (respecting its range), and write the merged outline (qpdf JSON or pdfrx). Acceptance: a merge of two bookmarked PDFs has both trees, each pointing at the right output pages; a file with a range keeps only entries inside it.
