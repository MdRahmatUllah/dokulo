# DK-1070 · Gradle fits the shared machine: 2 GB heap, 1 GB Kotlin daemon, no idle daemon

Added by agent-0, 2026-10-08 16:28.

packages/app_pdf/android/gradle.properties carries the Flutter template's org.gradle.jvmargs=-Xmx8G -XX:MaxMetaspaceSize=4G, and Gradle's daemon stays resident after a build (1-1.7 GB seen). On the team's shared machine (two teams, WSL, two emulators) free memory sits at 3-5 GB, so APK builds and device checks can't run under the 6 GB floor. Change: -Xmx2G -XX:MaxMetaspaceSize=1G, kotlin.daemon.jvmargs=-Xmx1G, org.gradle.daemon=false (each build's JVM exits when it's done). Acceptance: a dev debug APK builds; its peak memory is recorded in the PR; MEMORY.md gets the device-run floor that measurement supports.
