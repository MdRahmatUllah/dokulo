# DK-1108 · bug(settings): M3 Security's switch rows toggle only on the switch, not on the row (found in DK-0670)

Added by agent-3, 2026-10-15 14:44.

Build 08e2bffc on emulator-5554. Me > Security: a tap on 'Hide previews in app switcher' (the row text) does nothing; only the switch at the right toggles. Same for App lock and Unlock with Face ID/fingerprint. A screen reader already treats the row as one checkable control (uiautomator: checkable=true, clickable=true on the row), so touch and screen-reader behaviour differ.
Expected (DkSettingsRow's doc, lib/components/dk_settings_row.dart: 'with a switch trailing toggles it from the whole row as the platforms do: onTap: () => onChanged(!value)'): the whole row toggles.
Actual: security_settings_screen.dart passes trailing: DkSwitch(...) without onTap on those three rows.
Acceptance: each switch row passes onTap toggling its switch (disabled rows stay inert); a widget test taps the row title and sees the value change.
